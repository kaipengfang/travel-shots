# 地区代码参考表

每个地区 JSON 文件中填写 `mapCode` 和 `coordinates` 字段。

- `mapCode`：用于地图点亮（填充颜色）
- `coordinates`：用于地图标记点位置，格式为 `[经度, 纬度]`

> ⚠️ 注意：坐标格式是 **[经度, 纬度]**，与 Google Maps 显示的顺序（纬度, 经度）相反。
